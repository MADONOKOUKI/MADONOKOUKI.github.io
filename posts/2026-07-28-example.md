これはサンプル記事です。`draft: true` の間は公開されません。公開したくなったら `draft: false` にして
`python3 scripts/build_blog.py` を実行し、生成された `blog/` をコミットします。

## 記事を追加する手順

1. `python3 scripts/new_post.py "タイトル"` で雛形を作る
2. `posts/YYYY-MM-DD-slug.md` を書く
3. `python3 scripts/build_blog.py --drafts` で下書きも含めてローカル生成して確認する
4. `draft: false` にして `python3 scripts/build_blog.py` → コミットして push

GitHub 上で `posts/` に Markdown を追加した場合は、Actions が自動でビルドして `blog/` を更新します。

## 使える記法

- **太字**、*斜体*、`インラインコード`
- [リンク](https://madonokouki.github.io/)（外部リンクは自動で別タブ）
- 箇条書きと番号付きリスト、引用、水平線

> 引用はこう書きます。長い行は自動で連結され、日本語の間には余計な空白が入りません。
